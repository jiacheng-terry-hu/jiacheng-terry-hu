## What I'm working toward

My study goals build on my Berkeley Data Science background and follow the [UChicago Applied Data Science curriculum](https://datascience.uchicago.edu/education/masters-programs/ms-in-applied-data-science/course-progressions/):

| Study direction | What I want to develop |
| :--- | :--- |
| **Statistical modeling** | Test hypotheses, interpret uncertainty, and examine model assumptions. |
| **Data engineering & cloud systems** | Build dependable Python and SQL workflows from ingestion to analysis. |
| **Machine learning & AI** | Develop and evaluate models with attention to generalization and responsible use. |
| **Time series & forecasting** | Understand temporal patterns and assess forecast reliability. |
| **Communication & collaboration** | Translate analytical results into clear recommendations for different audiences. |

My broader goal is to take a well-defined question through data preparation, modeling, evaluation, and a useful final deliverable. I want my work to be reproducible, grounded in evidence, and clear about its limitations.
